Problématique

  • Déséquilibres emploi / habitat → pression sur les déplacements
  • Décideurs : besoin d’une vue synthétique spatiale
  • Contrainte : données agrégées, pas de surveillance individuelle

Vision produit

Aider urbanistes et élus à localiser flux majeurs et déséquilibres territoriaux pour prioriser diagnostics et investissements.

Méthodes

  • M2 : heuristiques dortoir / emploi / mixte + top corridors OD
  • M6 : eh_index = 1 − |J−P|/(J+P) ∈ [0, 1]
  • M1 : desire line ≠ itinéraire routier
  • Démo : proxies OD synthétiques (pipeline prêt pour OD réel)

Qualité & conformité

  • QA smoke API : 19/19 OK
  • RGPD : agrégation zone→zone · k ≥ 5 · pas d’IDs individuels
  • Sécu MVP : `.env` · CORS restrictif · Swagger off en prod

Difficultés & apprentissages

  • Graphe routier fragmenté → points démo connectés + Dijkstra bbox
  • Perf spatiale → bbox + LIMIT
  • Scope : tenir le Must, ne pas sur-promettre M3/M4

Perspectives

  • M6 → accessibilité type 2SFCA / isochrones
  • M2 → clustering si validation métier
